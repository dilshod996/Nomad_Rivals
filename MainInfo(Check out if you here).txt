# Nomad Rivals

Nomad Rivals is a mobile game project developed by Kaja Games, inspired by traditional Central Asian equestrian sports, including Ko‘pkari.

## Source Code

The complete source code of Nomad Rivals is maintained in a private repository because it contains proprietary game systems, licensed assets, backend integrations, and other confidential project resources.

If the President Tech Award evaluation team requires access to the source code for technical review, we are happy to provide private repository access upon request.
